# FinishBit

FinishBit provides reusable capabilities for AI tasks. Its product language emphasizes completing tasks with existing capabilities.

## Language

**FinishBit**:
The product and brand that provides reusable task capabilities to AI agents.
_Avoid_: Fini

**fnsh**:
The command-line interface to FinishBit.

**Bit**:
A small, focused task capability in brand language. Its formal name in contracts and technical documentation is Operation.
_Avoid_: Task Bit as a separate technical entity

**Operation**:
A discoverable task capability with a defined contract for inputs, options, results, and errors. One Operation can complete a step within a larger task.

**Provider**:
The source of an Operation’s implementation. For example, ffmpeg provides the video.trim Operation.
